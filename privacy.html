Privacy Policy

Last updated: 7 November 2026

1. Browser calculations

The calculator code processes salary, leave and comparison inputs in your browser. It does not submit a calculator form to a payroll server. Reports are estimates generated from the inputs you provide.

2. Preferences and history

Some tools save recent calculations, salary preferences, employee type and colour theme in this browser’s local storage. Other people using the same browser profile may be able to see saved history. Resetting a form does not erase all stored history. Use the tool’s Clear All control where available, or clear this site’s data in your browser to remove stored entries.

3. Reports and external links

Copy, export, print and share actions are initiated by you. A copied or downloaded report can include the details you entered. Check it before sending it to anyone. Links to official sources open external websites with their own privacy practices.

4. Hosting and third-party services

The reviewed site code does not load an AdSense advertising script or an analytics measurement tag. This statement describes the calculator code reviewed on the update date. The site is hosted by Vercel; consult the hosting provider’s privacy information for its own services.

5. Technical feedback

The project repository is SG Salary Calculator on GitHub. Avoid posting personal salary, employment documents or private details in public feedback.
